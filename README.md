# פסטיבל הג'אז תל אביב-יפו 2026 — מיני-סייט

אתר סטטי (HTML/CSS/JS) עם לו"ז וסימון מועדפים (נשמר בדפדפן).

## איך הלו"ז מתעדכן
האתר קורא בכל טעינה את הגיליון "ג'אז 2026 – לו"ז לאתר (ציבורי)" ב-Drive,
שמושך (IMPORTRANGE) רק את לשונית "לוז" מגיליון העבודה. שאר הלשוניות (תקציב, טלפונים) לא מתפרסמות.
עדכון בלשונית "לוז" יופיע באתר תוך כמה דקות.

- תא עם שעות בתוכו (למשל `18:00-19:00 שם`) — השעות נלקחות מהתא.
- תא בלי שעות — מתחיל בשעה של השורה, ונגמר בהופעה הבאה באותה במה (עד שעה).
- שמות לתצוגה, תקלוטים והדליינרים: `names.js`
- גיבוי אם הגיליון לא זמין: `data.js`
